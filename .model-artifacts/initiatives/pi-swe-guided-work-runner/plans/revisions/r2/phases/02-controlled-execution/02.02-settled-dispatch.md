## Goal and observable behavior

After a valid checkpoint and settled turn, queue at most one exact canonical skill prompt, re-inspect artifacts before every continuation, and use the existing completion transaction when evidence permits.

## Scope

- Bind `agent_settled` continuation to one persisted dispatch token and active run lease.
- Use `sendUserMessage` with prompt-template expansion only when idle and policy permits.
- Generate bounded prompts naming exact canonical identity, required reads, stage, and checkpoint obligation.
- Reinspect canonical state and evidence; dispatch implement/verify/review/finalize or perform guarded completion.
- Stop at contract/initiative target, user/human gate, invalid state, missing checkpoint, retry/budget exhaustion, or completion failure.

## Non-goals

Bypassing stage skills, parsing free-form assistant prose as evidence, automatic plan approval, or parallel dispatch.

## Expected files

- `extensions/pi-swe/src/pi/events.ts` or a focused `src/pi/work-runner.ts`.
- `extensions/pi-swe/index.ts` wiring.
- `extensions/pi-swe/src/completion.ts` only if an existing public boundary must be reused without semantic change.
- Focused event/controller tests.

## Incorporated specialist decisions

Observe `agent_settled`, persist intent before send, dispatch only one expanded fixed-template skill prompt, and stop on uncertain crash recovery rather than duplicate. Reinspect canonical artifacts before acting; never parse prose. Guided and autonomous modes both pause for material replanning, plan approval, unsafe/external actions, and missing capabilities. Red tests cover persist-before-send and checkpoint-before-continuation crash windows.

## Acceptance criteria

- AC-03, AC-05, AC-06, AC-07, AC-08, and AC-09 pass.
- Exactly-once dispatch holds across duplicate settled events and restart.
- Completion always goes through current evidence/hash/claim/journal checks.

## Verification

Red-first fake Pi event tests for clean contract, next contract, verify-fix, review-replan pause, duplicate settled event, missing checkpoint, user stop, budget exhaustion, restart, and completion rejection; then `npm run test:swe`, `npm run typecheck`, and `npm run check:pi-api`.

## Rollback

Disable/remove event wiring; persisted runner state becomes inert and canonical artifacts are unchanged.
