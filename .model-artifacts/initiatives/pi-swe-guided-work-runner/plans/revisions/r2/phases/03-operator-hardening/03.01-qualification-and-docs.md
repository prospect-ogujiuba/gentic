## Goal and observable behavior

Ship conservative defaults, comprehensive lifecycle/recovery coverage, and operator documentation that makes autonomy and stop boundaries explicit.

## Scope

- Extend config/schema with bounded defaults and diagnostics.
- Add end-to-end fake-agent scenarios for contract and initiative targets, loops, restart, ambiguity, unsafe/external stops, and operator cancellation.
- Update README and E2E command guidance without changing `/swe orchestrate` semantics.
- Run focused and broad repository verification.

## Non-goals

Live provider qualification in default CI, deployment automation, or unrelated pi-swe refactors.

## Expected files

- `extensions/pi-swe/src/config/index.ts` and `extensions/pi-swe/pi-swe.schema.json`.
- `test/pi-swe*.test.ts` and/or the existing autonomy evaluation fixture.
- `extensions/pi-swe/README.md`.
- `extensions/pi-swe/docs/e2e-scenarios.md`.

## Incorporated specialist decisions

Default to guided contract scope with conservative bounded budgets. Cover duplicate/contradictory events, all safety gates, explicit recovery, old-config compatibility, unknown state versions, and guidance-only orchestration regression. Keep live-provider runs separate and explicitly authorized.

## Acceptance criteria

- AC-08 and AC-10 pass, and regression coverage confirms AC-01–AC-09.
- Defaults are guided, bounded, and opt-in; configuration errors fail closed.
- Documentation distinguishes runtime commands, skills, authority, and user gates.

## Verification

`npm run test:swe`, `npm run typecheck`, `npm run check:pi-api`, `npm run check:resources`, `npm run check:model-artifacts`, plus documented manual fresh-session start/resume/stop scenarios.

## Rollback

Revert additive config/docs/tests and disable the work runner; existing guidance-only orchestration remains.
