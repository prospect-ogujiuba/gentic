## Architecture and sequencing

1. Define an immutable normalized pressure policy and a pure O(1) evaluator/reducer with injected time.
2. Load/validate project and global configuration once using existing Gentic precedence conventions; unknown versions or invalid ordering fall back safely with bounded diagnostics.
3. Integrate the reducer only with existing measured usage-bearing lifecycle hooks and fakeable UI notification boundaries.
4. Add pressure status to maintained report/JSON/HUD snapshots; do not make `pi-hud` own policy.
5. Qualify privacy, lifecycle cleanup, compatibility, and full-suite behavior.
