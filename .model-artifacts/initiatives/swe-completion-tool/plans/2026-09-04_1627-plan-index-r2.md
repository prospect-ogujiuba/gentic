## Incorporated specialist decisions

- Separate non-mutating resolution from the existing mutation transaction.
- Require explicit `confirm: true` before resolution I/O.
- Infer topic only from one unambiguous active canonical initiative and contract only from its `activeContract`; never prefer chat/todo/lexical candidates.
- Recompute contract, review, and verification hashes; reuse one strict closed-envelope parser.
- Enumerate sorted direct report files without following symlinks, bounded to 200 entries, 2 MiB/file, and 16 MiB aggregate.
- Reject multiple current approving review envelopes without chronology or downstream-validity tie-breaking.
- Trust the unchanged transaction's under-claim reinspection for derivation-to-mutation races and concurrent writers.
- Register an additive Google-compatible tool schema and retain `/swe complete`/direct API unchanged.
- Drive implementation with actual Red evidence in registration → resolver → evidence safety → delegation order.
