## Goal

Register the concise LLM-callable tool, route it through the resolver and existing transaction, and document its safety contract.

## Observable behavior

A call with `confirm: true` and valid explicit or inferable identity completes through the existing transaction; false confirmation or invalid derivation returns a compact failure. `/swe complete` behaves unchanged.

## Scope and non-goals

Scope: Pi tool schema/registration, compact result formatting, integration tests, README/e2e docs, and affected test doubles. Non-goals: replacing the command, adding UI prompts, or autonomous verification/review.

- Depends on: `P01-C01`.
- Entry inputs: approved resolver contract and Pi `registerTool` contract.

## Acceptance criteria

- Register exact tool name/schema with required explicit confirmation and Google-compatible enum.
- Default `next` to `advance`; support `clear`.
- Preserve low-level command/API behavior and transaction result semantics.
- Return bounded actionable content/details and throw only for actual tool execution failure contracts.
- Update tests/docs that currently state no model-callable pi-swe tool exists.

## Verification

Tool-registration schema test, direct execute tests, existing completion and fault-injection regression tests, `npm run test:swe`, `npm run typecheck`, `npm run check`, and `npm test`.

## Rollback / migration constraints

Additive tool only; rollback removes registration/docs/tests. No canonical data rewrite.
