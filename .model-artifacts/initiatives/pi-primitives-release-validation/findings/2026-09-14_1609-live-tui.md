# Live Pi TUI startup and reload evidence

Ran Pi 0.84.2 in a temporary project and isolated HOME/XDG_CONFIG_HOME. A copied current `extensions/pi-primitives/` was placed in the documented auto-discovered `.pi/extensions/pi-primitives/` location and the project was approved for this run.

Observed in the real TUI on startup:

- `[Extensions] pi-primitives`
- footer/status: `4 registered`
- no primitive registration warning

Submitted `/reload` through the interactive TUI. Pi displayed `Reloaded keybindings, extensions, skills, prompts, themes, and context files`; `pi-primitives` remained loaded and the status remained exactly `4 registered`, with no failed/duplicate status or warning. The existing automated registration test separately asserts exactly three `before_agent_start` hooks, including across the intentional no-op `whimsical` configuration states.

The TUI process was terminated after observation. Temporary HOME, project, and copied extension resources were removed.
