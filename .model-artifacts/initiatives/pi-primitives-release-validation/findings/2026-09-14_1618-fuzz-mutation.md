# Seeded fuzz and mutation results

Added deterministic tests:

- `test/pi-primitives-fuzz.test.ts`: 2000 seeded recursive/cyclic/accessor/proxy structures; exact character, depth, node, and property boundary neighborhoods; 500 generated trigger definitions; 300 generated configs; 200 contained path cases; traversal/symlink attempts; and 300 hostile thrown values.
- `test/pi-primitives-mutation.test.ts`: isolated copies of pi-primitives receive ten deliberate boundary/security regressions. The focused suite must fail for every mutant without modifying the worktree.

All fuzz invariants pass: traversal never leaks an exception, flattened output remains within 32768 characters, invalid trigger/config inputs fail through bounded diagnostics, safe dot-prefixed paths remain readable, traversal and symlink escapes fail while later registrations continue, and diagnostic output remains single-line and at most 512 characters.

Mutation testing initially found two weak checks rather than production defects:

1. The inherited-property boundary fixture exceeded both the correct and off-by-one mutant limits; it was tightened to the exact boundary.
2. The duplicate-disabled-name case asserted only a generic config failure, which an unrelated unknown-name diagnostic also satisfied; it now asserts the specific validation error.

Final mutation score for the selected critical operators is 10/10 killed: depth, character, property, trigger-count, empty-match regex, exact-heading idempotence, config byte boundary, resource path containment, diagnostic length, and duplicate disabled-name validation.
