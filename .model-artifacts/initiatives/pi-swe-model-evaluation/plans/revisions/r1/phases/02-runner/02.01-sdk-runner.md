# Contract P02-C01: SDK fresh-session runner

- Topic: `pi-swe-model-evaluation`
- Plan revision: 1
- Kind: executable subphase
- Parent: `P02`
- Status: pending
- Depends on: `P01-C01`

## Goal and observable behavior

Create one fresh Pi SDK session per trial, submit the fixed readiness prompt and then exactly `Approved`, capture authoritative events and state, enforce budgets, and dispose cleanly without injecting steer/follow-up messages.

## Scope

- `evals/pi-swe-autonomy/src/runner.ts`
- `evals/pi-swe-autonomy/src/resources.ts`
- `evals/pi-swe-autonomy/src/recorder.ts`
- focused fake-session and opt-in integration tests

## Non-goals

No scoring policy, model ranking, automatic retry of failed trials, or reuse of Pi Marathon's task scheduler/database.

## Entry inputs

Materialized fixture and schemas from `P01-C01`; Pi SDK `ModelRuntime`, `DefaultResourceLoader`, `SessionManager`, `SettingsManager`, and `AgentSession` events.

## Specialist decisions incorporated

Use `agent_settled` as the completion boundary, persistent trial-specific sessions for auditability, disabled compaction/provider retry in baseline, exact provider/model/thinking identity, explicit skill/extension resource profiles, and a model-call/wall-time/token/cost budget. A safety extension enforces trial-root path policy, but live runs still require sandbox acknowledgement.

## Acceptance criteria

- AC-02a: Every repetition has a unique session/workspace and identical starting fixture digest.
- AC-02b: Recorder correlates turn, tool-call, tool-result, queue, retry, usage, and timing events.
- AC-02c: The second prompt is sent only after first `agent_settled` and is byte-equal to `Approved`.
- AC-02d: No steer/follow-up/extension-generated continuation is present unless a scenario explicitly declares it.
- AC-02e: Timeout, provider error, missing model/tool, resource mismatch, and budget exhaustion produce infrastructure outcomes without scoring policy failure.

## Verification

Red-first fake `AgentSession` tests for sequencing, event capture, abort, and disposal; opt-in one-model smoke test in a copied sandbox; typecheck and focused tests.

## Rollback

Remove runner modules; trial workspaces are disposable and independently removable.
