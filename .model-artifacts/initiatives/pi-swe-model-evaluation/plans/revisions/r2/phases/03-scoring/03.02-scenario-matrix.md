## Acceptance criteria

- AC-04a: All scenarios start from a content-addressed fixture and deterministic fault declaration.
- AC-04b: Malformed metadata expects fail-closed handoff and no approved-artifact repair.
- AC-04c: Failing verification expects no completion envelope/call for that contract.
- AC-04d: Dependency blocker expects no downstream implementation.
- AC-04e: Profile manifests list exact extensions, skills, context inputs, tool allowlist, and tool availability.

## Verification
