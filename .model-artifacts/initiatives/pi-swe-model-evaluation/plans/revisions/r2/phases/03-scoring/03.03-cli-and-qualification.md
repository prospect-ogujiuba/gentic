# Contract P03-C03: Qualification CLI and reporting

- Topic: `pi-swe-model-evaluation`
- Plan revision: 2
- Kind: executable subphase
- Parent: `P03`
- Status: pending
- Depends on: `P03-C02`

## Goal and observable behavior

Provide a dry-run/smoke/qualification CLI that runs a declared model matrix under budgets and emits machine-readable plus concise Markdown aggregate reports.

## Scope

- `evals/pi-swe-autonomy/src/cli.ts`
- `evals/pi-swe-autonomy/src/aggregate.ts`
- `evals/pi-swe-autonomy/README.md`
- `package.json` script `eval:swe`
- CLI/aggregation tests

## Non-goals

No default CI provider spending, leaderboard, daemon, web UI, or automatic policy edits.

## Entry inputs

All earlier contracts and authenticated model selectors supplied by the operator.

## Specialist decisions incorporated

Incorporates `.model-artifacts/initiatives/pi-swe-model-evaluation/findings/2026-09-11_1214-security-operations-compatibility.md` and `2026-09-11_1214-tdd-plan.md`. Sequential mutating trials are the default; bounded optional concurrency is allowed only across isolated workspaces. Smoke uses one trial; qualification requires at least 20 valid trials per model/scenario. Report Wilson confidence intervals, distributions, infrastructure exclusions, cost, tokens, time, Pi/Gentic/model identities, resource manifests, fixture/prompt hashes, and raw-run digests. Redact credentials, bound embedded trace excerpts, store raw traces outside Git with restrictive permissions where supported, and fail compatibility preflight before model calls.

## Acceptance criteria

- AC-05a: `--dry-run` validates resources/models/scenarios/budgets without a model call.
- AC-05b: `--smoke` performs exactly one declared live trial after sandbox acknowledgement.
- AC-05c: `--qualify` refuses fewer than 20 valid trials per model/scenario and enforces call/cost/time ceilings.
- AC-05d: Promotion requires at least 90% clean-path success and zero critical violations; infrastructure failures remain separately visible.
- AC-05e: Aggregate JSON is deterministic and Markdown is regenerated from it.
- AC-05f: Documentation gives exact reproduction and interpretation steps.

## Verification

Red-first CLI parsing/budget/refusal tests, aggregate golden tests, `npm run typecheck`, focused suite, `npm run test:swe`, and `npm run check`; authenticated qualification remains an explicit manual command.

## Rollback

Remove package script, evaluator modules, and tests. No default test or release workflow depends on live model access.
