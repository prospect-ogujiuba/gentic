## Observable behaviors and Red order

1. **Fixture reproducibility — unit/integration:** two copies have the same digest and independent writable paths. Red before materializer implementation.
2. **Schema rejection — unit:** unknown versions and incomplete identities reject. Red before decoders.
3. **Two-prompt sequencing — integration with fake AgentSession:** the runner waits for first `agent_settled`, sends exactly `Approved`, records no injected queue message, and disposes. Red before SDK runner.
4. **Budget/abort classification — integration:** timeout/provider failure becomes infrastructure outcome and cannot become a policy score. Red before runner error handling.
5. **Clean trace scoring — unit:** ordered implementation, successful command evidence, valid envelopes, completion advancement, and final reconciliation pass. Red before scorer.
6. **Violation scoring — table unit tests:** reordered contract, prose-only verification, completion retry, approved-artifact mutation, dependency bypass, and incomplete finalization produce exact findings. Red before each scoring rule.
7. **Scenario expectations — integration/golden:** malformed metadata, failing verifier, and dependency blocker stop without forbidden completion/mutation. Red before scenario matrix.
8. **Qualification refusal and aggregation — unit/CLI:** insufficient repetitions or missing sandbox/budget acknowledgement refuses; stable inputs produce stable Wilson statistics/report. Red before CLI.
9. **Authenticated smoke — opt-in end-to-end:** one real isolated trial produces a complete trace/score or explicit infrastructure failure. Never part of default tests.
