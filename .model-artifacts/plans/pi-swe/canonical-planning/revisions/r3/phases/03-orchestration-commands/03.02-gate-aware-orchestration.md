# Subphase 03.02: Gate-aware orchestration recommendations

Created: 2026-08-30
Purpose: Recommend the exact next planning or execution stage from canonical evidence.

## Goal and observable behavior

Given a resolved initiative inspection, orchestration returns one deterministic recommendation with stage, reason, required read paths, intended write artifact, blocking reasons, and active/ready contract. Draft plans route through specialist/plan review before implementation; stale or legacy plans never route to implement.

## Dependencies

- `03.01`

## Expected files

- Refactor `extensions/pi-swe/src/orchestrate.ts`.
- Extend `test/pi-swe-lifecycle.test.ts` orchestration fixtures.

## Implementation contract

1. Replace fixed required-file readiness with gate/readiness view consumption.
2. Recommend `specify`, `diagnose`, `plan`, `dsa-assess`, `tdd-plan`, `plan-review`, `plan-revise`, `implement`, `verify`, `implementation-review`, `finalize`, `complete`, or blocked handoff as appropriate while mapping to existing skill names.
3. Require exact read paths: manifest, active spec/plan, active contract, relevant finding/evidence/state.
4. Name the expected write artifact path shape without writing it.
5. For multiple ready contracts, select deterministic lowest ID and report other ready IDs; do not imply parallelism unless approved.
6. Legacy mode recommends adoption/plan review. Ambiguous, invalid, stale, no-verifier, and repeated-failure states return actionable human handoffs.
7. Bound output data and keep pure recommendation logic separate from filesystem inspection.

## TDD boundary

Red first: complete files but draft approval recommends plan review, not implementation. Add canonical feature, bug/diagnosis, DSA, TDD plan, stale revision, legacy adoption, ambiguity, contract verify/review, next contract, and finalize scenarios. Test level: unit/integration.

## Acceptance criteria

- Same inspection input produces deep-equal recommendation.
- Every nonterminal recommendation names required artifacts or blocker remediation.
- Existing guidance-only guarantee remains.
- No recommendation relies on chat history.
